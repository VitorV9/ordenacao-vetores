# 🚀 Análise de Desempenho: Bubble Sort

Sistema em Ruby desenvolvido para testar e analisar o tempo de execução do algoritmo Bubble Sort. O programa gera três vetores de tamanho definido pelo usuário e apresenta o tempo que leva para gerar esses três vetores em diferentes maneiras de ordenação, crescente, decrescente e embaralhando e aplicando o algoritmo Bubble Sort para ordenar.

---

## 🛠️ Tecnologias

* **Linguagem:** Ruby
* **Dependências:** Nenhuma, somente uso de métodos nativos do Ruby.

---

## ⚙️ Como Funciona

Ao iniciar, o programa solicitará dois parâmetros principais:
1. **Tamanho do vetor (N):** A quantia de números o vetor ira conter.
2. **Amostragem (M):** A quantia de testes que o algoritmo rodará no cenário aleatório para calcular um tempo médio.

Após receber os dados, o sistema executa a ordenação e exibe uma tabela de tempos para os cenários:
* **Crescente:** O vetor já está previamente ordenado do menor para o maior.
* **Decrescente:** O vetor está ordenado de forma totalmente invertida (maior para o menor).
* **Aleatório:** O vetor possui números embaralhados, que serão ordenados com o algoritmo Bubble Sort.
